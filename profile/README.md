# We bouwen open source voor de overheid van nu en morgen

Het Digi Gilde is een team van product owners, designers en engineers binnen [Rijksorganisatie ODI](https://www.rijksorganisatieodi.nl/). We ontwikkelen softwareproducten en prototypes, en we proberen bestaande open source oplossingen uit. Veel van dat werk doen we voor de [Nederlandse Digitale Dienst](https://digitaledienst.overheid.nl).

Meer over wie we zijn en hoe we werken lees je in het [Digi Handboek](https://digihandboek.rijks.app/).

## Hoe we werken

We geven de voorkeur aan open source en streven naar maximale openheid in onze processen. Bestaande kennis en bewezen methoden gebruiken we opnieuw, en wat we leren delen we.

We laten zien hoe iets kan en helpen anderen om dit voor elkaar te krijgen. De rest staat in [onze principes](https://digihandboek.rijks.app/werkwijze/principes/). Daarnaast volgen we de [NeRDS](https://nerds.digitaledienst.overheid.nl/), de Nederlandse Richtlijn Digitale Systemen.

## Meedoen

- Een fout gevonden, of een idee? Open een issue in de repository waar het om gaat.
- Een wijziging voorstellen doe je met een pull request. Heeft een repository een `CONTRIBUTING.md`, dan staat daarin hoe dat werkt.
- Een kwetsbaarheid meld je vertrouwelijk via digigilde@rijksoverheid.nl, niet in een openbaar issue.
- Welke licentie geldt, staat per repository in het licentiebestand.

Vragen kun je stellen via digigilde@rijksoverheid.nl. Werk je bij de Rijksoverheid, dan vind je ons ook op [Mattermost](https://digihandboek.rijks.app/contact/#mattermost).

## Werken bij het Digi Gilde

Het Digi Gilde hoort bij Rijksorganisatie ODI. Of er vacatures zijn zie je op [Werken bij ODI](https://www.rijksorganisatieodi.nl/werken-bij-rijksorganisatie-odi). Hoe je bij ons begint, lees je in de [onboarding](https://digihandboek.rijks.app/onboarding/).
